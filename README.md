# Big O Notation Visualizer

A simple web app for exploring algorithm complexity. Switch between tabs to:

- **Big O Growth** — pick complexities, adjust `N`, see how they grow on a graph, and run small code examples with the current `N`.
- **Algorithms** — watch sorting and searching algorithms step by step.
- **Data Structures** — explore arrays, linked lists, stacks, queues, hash tables, binary trees, and graphs visually, with common operation costs.

## Stack

- React + TypeScript
- Recharts
- Tailwind CSS
- Vite

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```
