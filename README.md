# Big O Notation Visualizer

A simple web app for visualizing Big O growth. Pick complexities, adjust `N`, see how they grow on a graph, and run small code examples with the current `N`.

## Stack

- React + TypeScript
- Recharts
- Tailwind CSS
- Vite

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```
